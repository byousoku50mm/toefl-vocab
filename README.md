# 词汇发音 · 托福英语 + TOPIK 韩语

单文件离线词库，**两套内置卡组**（打开即用，不需要任何导入）：

| 内置卡组 | 内容 |
| --- | --- |
| 📚 托福词汇 | 英语 4510 词：音标、词性、释义、例句、近义反义，点击朗读、左滑已记住、右滑垃圾桶 |
| 📚 TOPIK 词汇 | 韩语 5965 词（한국어 학습용 어휘 목록）：标准发音（含音变）· 词性 · 等级 · 汉字 · 中文释义 · 例句 |

顶部标签切换两套词库；卡组（自建分组）、标记、白板、笔记、朗读都是共用的。
韩语按初声（ㄱㄲㄴ…ㅎ）分组，朗读自动挑韩语语音（ko-KR）。

## 在线使用

打开本仓库的 GitHub Pages 网址即可。iOS / Android 上可以「添加到主屏幕」，
之后**断网也能用**（service worker 把整页缓存到本机）。

## 离线使用

`index.html` 双击就能打开，但 **file:// 下没有 service worker** ——
要真正离线，必须通过一个 **https** 网址访问过一次。

Android 也可以直接装 `english-vocab.apk`（调试签名，词库全部打在包里，装完即离线可用）。

## 你的数据在哪

已记住、垃圾桶、卡组、白板、笔记全部存在**你自己设备的浏览器**里
（localStorage），不在这个仓库里，也不会随仓库同步。
换设备请用应用内的「导出备份」。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 全部内容（两套词库、例句、样式、脚本都内联在里面）|
