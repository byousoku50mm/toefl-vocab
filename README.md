# 托福词汇 · 英语单词发音

单文件离线单词库：4510 词、每词 2 条例句、点击朗读、左滑已记住、右滑垃圾桶。

## 在线使用

打开本仓库的 GitHub Pages 网址即可。iOS / Android 上可以「添加到主屏幕」，
之后**断网也能用**（service worker 把整页缓存到本机）。

## 离线使用

`index.html` 双击就能打开，但 **file:// 下没有 service worker** ——
要真正离线，必须通过一个 **https** 网址访问过一次。

## 你的数据在哪

已记住、垃圾桶、卡组、白板、笔记全部存在**你自己设备的浏览器**里
（localStorage），不在这个仓库里，也不会随仓库同步。
换设备请用应用内的「导出备份」。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 全部内容（词库、例句、样式、脚本都内联在里面）|
| `sw.js` | service worker，负责离线缓存 |
| `manifest.webmanifest` | 「添加到主屏幕」用的应用信息 |
| `icon-*.png` `favicon-32.png` | 主屏幕图标 |
