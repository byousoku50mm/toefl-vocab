托福词汇 · 放到 GitHub Pages（手机离线可用）
================================================
为什么必须这么做：service worker（离线缓存的唯一手段）只在
**https 网址**下才存在。局域网 http://192.168.x.x 不行 ——
浏览器根本不提供这个接口，离线永远做不成。GitHub Pages 免费给 https。

全程大约 5 分钟，不需要装任何软件。

────────────────────────────────────────────
第 1 步：注册 / 登录 GitHub
────────────────────────────────────────────
打开 https://github.com 注册一个账号（免费）。已有账号就登录。

────────────────────────────────────────────
第 2 步：新建一个仓库
────────────────────────────────────────────
1. 右上角「+」→ New repository
2. Repository name 填一个英文名，例如：  toefl-vocab
3. 选 **Public**（免费账号必须公开；放心，里面没有你的个人数据 ——
   已记住/卡组/白板都存在你设备自己的浏览器里，不在这些文件里）
4. 不要勾 Add a README file
5. 点 Create repository

────────────────────────────────────────────
第 3 步：上传文件（网页拖拽，不用装 git）
────────────────────────────────────────────
1. 在新仓库页面点 「uploading an existing file」
   （或 Add file → Upload files）
2. 打开电脑上这个文件夹：  …\default-workspace\app\
3. 把里面的**全部文件**一起拖进网页的上传区：
      index.html
      manifest.webmanifest
      sw.js
      icon-180.png
      icon-192.png
      icon-512.png
      favicon-32.png
      README.txt          （这个可以不传）
   注意：是拖**文件**，不是拖 app 这个文件夹本身 ——
   要让 index.html 直接躺在仓库根目录，网址才最干净。
4. 下方 Commit changes 点一下（等它传完；index.html 有 2.9 MB，慢一点正常）

────────────────────────────────────────────
第 4 步：开启 Pages
────────────────────────────────────────────
1. 仓库页面 → Settings（齿轮）
2. 左侧找到 Pages
3. Source 选 **Deploy from a branch**
4. Branch 选 **main**，右边的目录选 **/ (root)**
5. 点 Save
6. 等 1 分钟左右，刷新这个页面，顶部会出现一行：
      Your site is live at https://<你的用户名>.github.io/toefl-vocab/
   这就是你的网址。

────────────────────────────────────────────
第 5 步：手机上装成 App（关键：按顺序）
────────────────────────────────────────────
1. iPhone / iPad 用 **Safari** 打开那个网址
   （必须是 Safari；iOS 上 Chrome 不能添加到主屏）
   安卓用 Chrome。
2. **等页面底部出现这条提示**：
      ✓ 离线已就绪 —— 现在可以「添加到主屏幕」了
   它在把 3 MB 词库写进本机缓存；没出现之前别急着添加，装早了会黑屏。
3. 出现后再添加：
     iPhone / iPad：底部「分享」按钮 → 向下滑 → 「添加到主屏幕」→ 添加
     安卓：右上角菜单 → 「安装应用」/「添加到主屏幕」
4. 完成。以后断网也能从主屏图标打开，4510 个托福词汇都在。

────────────────────────────────────────────
以后想更新内容
────────────────────────────────────────────
在仓库里重新上传改过的文件即可。手机上刷新一下就能拿到新版
（页面的导航请求是"网络优先"，联网时永远取最新，不用清缓存）。

────────────────────────────────────────────
出问题怎么排查
────────────────────────────────────────────
· 底部一直显示「离线缓存需要 https 网址」
  → 你打开的还是 http 地址。确认地址是 https:// 开头。
· 底部一直显示「离线缓存还没写完」
  → 网络慢，保持联网多等一会儿再添加。
· 添加到主屏后断网打开是黑屏
  → 装早了。用 Safari 重新打开网址（联网）→ 等那条 ✓ 提示出现 →
    再打开主屏图标即可；或删掉图标重装一次。
· 断网时朗读没声音
  → 系统里没装英文语音包：设置 → 辅助功能 → 朗读内容 /
    语言与输入 → 文字转语音 → 下载英语（美国）。
