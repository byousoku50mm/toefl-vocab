英语词汇 · 可安装版（PWA）
=====================================

这是一个"装到手机上就是 App"的网页。装好后：
  · 主屏上有自己的图标，点开是全屏，没有浏览器地址栏
  · 断网也能用（词库已全部打包在里面）
  · 只有「联网加词」和「查词导入后爬词补全」两项需要联网

service worker 必须走 http(s)，file:// 直接打开是不行的 ——
所以需要把它放到一个能访问的网址上。任选一种：

一、局域网（最快，适合自己用）
   把整个 app 文件夹拷到电脑上，在文件夹里起一个静态服务器，例如
       npx serve .
       python -m http.server 8080
   然后在手机浏览器里访问  http://<电脑的局域网IP>:端口/
   手机和电脑要在同一个 Wi-Fi 下。

二、免费静态托管（适合发给别人）
   把 app 文件夹里的**全部文件**上传到任意静态托管：
       GitHub Pages / Netlify / Vercel / Cloudflare Pages
   得到网址后直接用手机打开。

安装方法
--------
Android（Chrome / Edge）：
   打开网址 → 右上角菜单 → 「安装应用」或「添加到主屏幕」→ 完成

iPhone / iPad（Safari，必须是 Safari）：
   打开网址 → 底部「分享」按钮 → 向下滑找到「添加到主屏幕」→ 完成
   注意：Chrome 在 iOS 上不能添加主屏应用，只能用 Safari。

Windows / macOS（Chrome / Edge）：
   地址栏右侧会出现一个"安装"图标，点一下即可装成桌面应用。

卸载
----
和普通 App 一样：长按图标 → 删除（或从系统的应用列表里卸载）。
不会影响你已有的标记、卡组与白板数据 —— 那些存在浏览器本地存储里。
